# Transporte

## Comandos necesarios para instalación

- `npm init -y`
- `npm install openai`
- `npm install dotenv`

> Revisar si en package.json está configurado   "type": "module",

## Comando para ejecutar node

- `node app.js`

## Situación

La inteligencia artificial funciona de aquella manera. Da una respuesta. En mi caso he querido que estuviese en ese formato, como un objeto literal. Así me evito tener que manejar TODO el churro que te suelta con su explicación de la operación. La parte mala es que me da una cifra muy dispar cada vez que le pido la misma operación. La parte menos mala es que tarda bastante en dar una respuesta🥲.
